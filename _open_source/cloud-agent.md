Cloud Agent is part of [HarvardMadSys's HybridInference](https://github.com/HarvardMadSys/hybridInference) ecosystem. It lets users run coding agents such as Claude Code and Codex on their repositories through a web interface, with persistent sandbox environments and GitHub integration.

I contribute to agent session management, shared workspaces, and reliable conversation forking and recovery.

The source code is available on [GitHub](https://github.com/HarvardMadSys/hybridInference-cloud-agent).
